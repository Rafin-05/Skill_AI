# Career Compass (Skill AI) 🧭

An interactive career orientation, skill gap analysis, and developmental roadmap application.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRafin-05%2FSkill_AI)

## 🚀 Features

- **Interactive Skill Gap Discovery**: Radar "compass rose" visualization for self-assessed vs. target role competencies.
- **Milestone Roadmap**: Step-by-step milestone tracking with task verification and evidence submission.
- **Coaching & Mentorship Interface**: Simulated coaching slot requests and review workflows.
- **Responsive & Accessible UI**: Clean survey-chart design system with full dark and light mode support.
- **Zero-Dependency Static App**: Runs immediately on any modern browser or static hosting platform.

## ⚡ Deploy to Vercel

### Option 1: One-Click Deploy
Click the button above or visit:
[https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRafin-05%2FSkill_AI](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRafin-05%2FSkill_AI)

### Option 2: Connect via Vercel Dashboard (Git Integration)
1. Go to your [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New..."** → **"Project"**.
2. Select **GitHub** and find repository `Rafin-05/Skill_AI`.
3. Click **Import**.
4. Settings:
   - **Framework Preset**: `Other` (automatically detected)
   - **Root Directory**: `./`
   - **Build & Output Settings**: Leave as default (no build step needed)
5. Click **Deploy**.

Any subsequent commits pushed to the `main` branch will automatically trigger production deployments on Vercel!
